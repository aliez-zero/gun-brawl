## 模块范围与验收

T10-R3 已将五位角色及全部混搭接入共用人体骨架，四套新美术、五张独立脸、六种头饰 / 八配色 / 三肤色、连续双手 IK、按服装区分的附件和 C05 基础动作 / 朝向 / 实战尺寸预览均已实现，见 [全角色交接](../updates/2026-10-18-all-character-rigs.md)。新开发使用 `characters/HumanoidRig.ts` / `HumanoidArt.ts` / `HumanoidView.ts`，按角色拆分画师文件；逐枪完整装填、表情 / 胜利动作与参考机性能仍待。

- **目标 / 需求**：F12，以及 F03 / F13 的可读性；A23。
- **拥有路径**：现有 `src/content/appearances.ts`、`src/ui/appearance/` 与 `src/presentation/characters/`；`ArenaRenderer.ts` 为共享接入点，由集成者维护，音效扩展需明确独立归属。
- **具体工作**：颜色、至少四帽四衣、预览、P1 / P2 配置；保护 / 命中 / 出界、箱子 / 炸弹 / 八枪可读表现；对齐配置驱动的角色 / 武器外观。
- **集成契约**：外观不改变物理和数值，设置交 T12；同色仍有编号 / 名称 / 轮廓；新增表现只消费状态 / 事件。
- **验收**：预览与实战一致，复活 / 重赛保留选择，无缺失资源；关闭震动后仍能理解命中；不靠单一颜色或声音表达关键状态。
- **依赖与边界**：不更换引擎，不引入无来源的第三方游戏素材，不重画全部 UI 导致其他任务失效。
