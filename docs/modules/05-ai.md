## 模块范围与验收

- **目标 / 需求**：F08；A19。消除训练台硬编码并补齐可观察的行为差异。
- **拥有路径**：`src/game/ai/BotController.ts`；建议新增 `src/game/ai/Navigation.ts`、`tests/ai.test.ts`。运行器接线归集成者。
- **具体工作**：从地图提取可站立平台与合法跳跃 / 穿台路线；断桥缺口与回台优先；无进展约一秒重规划；依据武器距离射击；消费箱子 / 炸弹公开状态抢箱与避爆。
- **集成契约**：只输出 `ActorInput`，不写核心角色状态；不额外增加跳跃 / 生命 / 推力；反应受种子和难度控制，不读取未来投放随机。
- **验收**：当前四图能完成合法对局，固定种子可复现，目标不存在 / 复活 / 淘汰时处理明确；三档可观察差异；不会反复走进同一缺口或从边缘追出；人类仍能正常击出 AI。
- **依赖与边界**：导航可先独立开发；抢箱 / 避爆和武器策略待 T01—T04 接入后再标完整完成。

## T05.4 交付结果

- `src/game/ai/BotController.ts` 只输出 `ActorInput`，不写核心状态。
- **炸弹威胁优先**：引信 < 1 秒且距离 < 半径 90% 时，向远离炸弹的方向移动；落地时优先跳跃脱离；停止射击。
- **抢箱**：340 px 内存在 active 箱子时，先朝箱子移动；箱子在更高处且落地时跳跃；不射击，避免被目标牵制。
- **近身投弹**：目标水平距离 90—260 px、垂直 < 80 px、仍有炸弹、冷却结束、自己未爆弹 < 2 时，按难度概率投弹；投弹帧不射击。难度概率：简单 0.2 / 普通 0.45 / 困难 0.75。
- 反应延迟、固定种子、平台恢复 / 攀爬逻辑保持不变；仍不做 A* / 全平台图，也不读取未来投放随机。
- `tests/ai.test.ts` 3 项：近身投弹边沿、远目标时先抢箱、近爆时反向移动 + 跳跃。
