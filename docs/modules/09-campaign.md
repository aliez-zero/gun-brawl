## 模块范围与验收

- **目标 / 需求**：F10；A21。实现 PRD C01—C06，线性解锁和独立成绩。
- **拥有路径**：建议新增 `src/content/campaign.ts`、战役进度服务、`src/ui/campaign/`、`tests/campaign.test.ts`。
- **具体工作**：固定地图 / AI / 武器池 / 目标，先开 C01；胜利解锁下一关；最佳成绩先比剩余生命再比耗时；失败 / 平局不解锁；已通关可重玩。
- **集成契约**：使用统一对局运行器和配置校验；战役身份与结果关联；进度和成绩一次提交；与 T12 约定统计口径，不算普通人机 / 自定义场次。
- **验收**：锁定关不可开始；修改自定义配置不污染战役；刷新保留合法进度；重复结算不重复解锁 / 计数；退出未完成局不解锁；结果页能重试 / 选关 / 返回。
- **依赖与边界**：四图与八枪已实现；关卡配置可先写，但缺多人 AI / 战役流程时不能宣布六关已完成。

## 当前接入

- `src/content/campaign.ts`：六关配置、进度归一、`createCampaignConfig`、`campaignScore`。
- `src/ui/GameUI.ts`：菜单“战役”第五模式、关卡选择（锁定 / 已通关 / 最佳成绩）、结果页下一关 / 重试本关 / 选择关卡。
- `src/app/GameApplication.ts`：锁定校验、种子 / `matchId` 新局、结果独立提交、下一关解锁。
- `src/storage/SaveStore.ts`：`campaign` 字段持久化；`recordCampaignResult` 只处理人类胜利，失败 / 平局不改进度，重复结果不再计分，战役不计普通人机统计。
- `src/game/core/types.ts` / `MatchSystem.ts`：`GameMode` 增加 `campaign`，结果携带 `campaignLevelId`。
- 测试：`tests/campaign.test.ts` 4 项。
- 仍待：逐关专属剧情 / 奖励、六关完整人工实战平衡验收；当前成绩只记录最佳分数，不单独展示历史成绩列表。
