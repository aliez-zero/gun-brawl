## 模块范围与验收

- **目标 / 需求**：F10；A21。实现 PRD C01—C06，线性解锁和独立成绩。
- **拥有路径**：建议新增 `src/content/campaign.ts`、战役进度服务、`src/ui/campaign/`、`tests/campaign.test.ts`。
- **具体工作**：固定地图 / AI / 武器池 / 目标，先开 C01；胜利解锁下一关；最佳成绩先比剩余生命再比耗时；失败 / 平局不解锁；已通关可重玩。
- **集成契约**：使用统一对局运行器和配置校验；战役身份与结果关联；进度和成绩一次提交；与 T12 约定统计口径，不算普通人机 / 自定义场次。
- **验收**：锁定关不可开始；修改自定义配置不污染战役；刷新保留合法进度；重复结算不重复解锁 / 计数；退出未完成局不解锁；结果页能重试 / 选关 / 返回。
- **依赖与边界**：关卡配置可先写，但缺三图 / 六枪 / 多人 AI 时不能宣布六关已完成。

## 开发子任务

按下列顺序推进。部分能力可先开发，但不能用占位行为替代真实依赖后勾选完整模块。

- [ ] **T09.1** 按 PRD 定义 C01—C06 的地图、AI、武器池和目标，复用统一配置校验。
- [ ] **T09.2** 实现线性解锁、锁定原因、可重玩和关卡配置与自定义隔离。
