## 模块范围与验收

- **目标 / 需求**：F07；A16、A17。把武器实例接入局内争抢，包含规则边界。
- **拥有路径**：建议新增 `src/game/systems/DropSystem.ts`、`src/game/systems/PickupSystem.ts`、`src/content/drops.ts`、`tests/drops.test.ts`；地图点位由 T04，状态与调度由集成者。
- **具体工作**：PRD 首次 / 后续 8 秒节奏、提前 1 秒预告、上限三箱、20 秒到期和末三秒提示；禁止危险 / 出生点附近落点；无安全点时跳过；武器池按权重归一，空特殊池合法。
- **集成契约**：种子随机可复现；通过 T01 入口换枪补满；箱子不当作地形；抢箱按距离、等距用明确种子流；新枪下一步开火。
- **验收**：同帧只发给一人，已出界角色不能拾取；上限 / 到期 / 空池 / 全点位不可用均有测试；倒计时 / 暂停不推进投放；加时与重置清理和重建策略明确。
- **依赖与边界**：武器切换与地图点位先稳定；不各自复制地图配置 / 武器定义，不在渲染层判归属。
