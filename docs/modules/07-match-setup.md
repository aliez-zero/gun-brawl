## 模块范围与验收

- **目标 / 需求**：F09；A20、A14 的多人场景。提供真正能开始的 2—4 人配置流程。
- **拥有路径**：`src/content/matches.ts`；建议新增 `src/game/core/validateMatchConfig.ts`、`src/ui/match-setup/`、`tests/match-config.test.ts`。
- **具体工作**：地图、生命、时限、槽位、每个 AI 难度、武器池；至少一人类，最多两人类、总计 2—4；关闭特殊投放合法；校验 ID 引用、重复角色 / 人类槽位、出生点与规则范围。
- **集成契约**：统一校验供 UI / 模拟器 / 战役复用；不从 DOM 直接构造未校验状态；重赛保留实际配置；返回配置页保留选择；最近配置保存交 T12。
- **验收**：一人 / 五人 / 重复槽位 / 无效地图被拒绝；有效二至四人完整对战；非并列者不进加时；人类淘汰后可观战至结果；返回和重开不会退回硬编码训练台。
- **依赖与边界**：先用已有能力做组件，完整功能要等待地图 / 武器 / AI / 投放接入；`GameMode` 与统计变化由集成者统一修改。

## 开发子任务

按下列顺序推进。部分能力可先开发，但不能用占位行为替代真实依赖后勾选完整模块。

- [ ] **T07.1** 提供共享配置校验器，检查人数、人类槽位、唯一 ID、地图 / 武器引用和数值范围。
- [ ] **T07.2** 实现独立配置组件：地图、生命、时间、二至四槽位、AI 难度和武器池。
- [ ] **T07.3** 允许只用基础枪；无效配置定位错误并禁用开始，输出统一合法配置。
- [ ] **T07.4** 向集成者交付开始 / 返回配置 / 重赛接口，向 T12 提交最近配置数据。
- [ ] **T07.5** 验证二至四人完整局、非并列者观战、多方加时及重赛配置不丢失。
