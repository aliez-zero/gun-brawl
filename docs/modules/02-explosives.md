## 模块范围与验收

- **目标 / 需求**：F03；A08、A12、A24。实现合法投掷、引信、反弹、范围推力、遮挡和自伤。
- **拥有路径**：建议新增 `src/game/systems/GrenadeSystem.ts`、`src/game/systems/ExplosionSystem.ts`、`tests/explosions.test.ts`；公共输入 / 事件 / 状态由集成者接入，键盘接入归 T06。
- **具体工作**：每命两枚、投掷间隔 0.6 秒、最多两枚未爆、2 秒引信；使用固定步长；实体遮挡，单向平台不遮挡；同次爆炸对每个角色一次；中心重叠默认向上。
- **集成契约**：爆炸服务同时服务炸弹与火箭；保护阻挡推力；主动投弹先解除保护；自身爆炸不产生自己的击出，也不覆盖此前有效敌方归因。
- **验收**：暂停时引信和运动冻结；拥有者出界后炸弹继续；爆炸遮挡 / 边缘衰减 / 自伤 / 归因有场景测试；重赛 / 加时 / 训练重置清理残留；引信只能触发一次。
- **依赖与边界**：推力需围绕当前手枪调参；不直接改 T01 所有的战斗文件。武器数量 HUD、投弹键和爆炸音效由集成清单接入。

## T02 交付结果

### 已实现

- `src/game/systems/ExplosionSystem.ts`：`ExplosionSystem implements ExplosionResolver`，返回 `ExplosionHit[]`，不直接改状态；`applyExplosionHits` 统一施加冲量、归因和 `hit` 事件。
- 爆炸中心命中时默认向上；距离线性衰减；实体平台遮挡；单向平台不遮挡；保护中的角色跳过。
- `src/game/systems/GrenadeSystem.ts`：每命 2 枚、0.6 秒投掷冷却、最多 2 枚未爆、2 秒引信、重力 1400、反弹 0.45、半径 150、爆心 360 / 边缘 90。
- 炸弹使用 AABB 近似碰撞，实体墙水平反弹，实体 / 单向平台垂直反弹；暂停时引信和运动冻结；拥有者出界后炸弹继续。
- 投弹成功先清除保护；自爆可以推动自己，但不写自己的 `lastHit`，也不覆盖之前的敌方归因。
- 事件：`bomb`、`bomb-empty`、`explosion`、`hit`；状态：`MatchState.bombs`、`ActorState.bombsRemaining` / `bombCooldown`。
- 复活 / 加时通过 `createActor` 重置到 2 枚；加时清空 `state.bombs`；重赛由新模拟实例天然清空。
- 集成顺序：`BattleSimulation` 在移动 / 射击之后、批量出界之前更新炸弹；出界归因仍由 `LifeSystem` 处理。

### 检查

- `tests/explosions.test.ts` 11 项：中心 / 边缘 / 中心重合、保护、实体遮挡、单向平台、自伤归因、投掷 / 冷却 / 数量、引信只触发一次、同时爆炸、暂停、拥有者出界、反弹、复活 / 加时清理。
- 类型检查通过；完整测试与构建结果见交付记录。
