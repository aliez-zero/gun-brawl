## 模块范围与验收

- **目标 / 需求**：F03、F05；A06、A07。基础手枪之外能实际获得、发射和耗尽五类枪。
- **拥有路径**：`src/game/systems/CombatSystem.ts`、`src/content/weapons.ts`；建议新增 `src/game/systems/WeaponSystem.ts`、`tests/weapons.test.ts`。公共角色 / 弹丸类型与初始化由集成者接入。
- **具体工作**：定义注册表与实例弹量；实现手枪、冲锋枪、步枪、霰弹、狙击；霰弹一次扣一发、五条二维弹道；火箭消费 T02 爆炸服务；普通弹仍首个有效碰撞即结束。
- **集成契约**：提供合法切枪 / 补满 / 恢复手枪入口给 T03 / T08；发射时固定弹丸参数；HUD 根据当前枪和剩余弹量显示；AI 可读有效射程等公开属性。
- **验收**：特殊枪耗尽只回退一次，不在同一时刻额外射手枪；复活 / 加时回手枪；换枪不改变飞行中的子弹；实体挡弹、单向平台不挡；保留边缘压制与单发回台回归。
- **依赖与边界**：火箭完成前可交付其他五枪但状态为部分完成；不自行实现第二套爆炸规则，不改主菜单或存档。
- **调参**：旧草案特殊枪数值整体弱于新手枪基准，需记录选择依据与实际试射；不能仅复制参数表就验收。

## 开发子任务

按下列顺序推进。部分能力可先开发，但不能用占位行为替代真实依赖后勾选完整模块。

- [ ] **T01.1** 建立武器注册表和实例，明确无限弹、有限弹量、射击冷却与合法切枪入口。
- [ ] **T01.2** 保持现有手枪手感，实现冲锋枪、步枪、狙击，记录与手枪基准的实际差异。
- [ ] **T01.3** 实现二维弹丸与霰弹散射，一次开火扣一发，弹丸保存发射时的命中参数。
- [ ] **T01.4** 接入 T02 爆炸服务完成火箭；验证实体、首个有效目标和剩余射程规则。
- [ ] **T01.5** 覆盖耗尽回退、切枪后在途弹丸、复活 / 加时复位；交付 HUD 与 AI 读取接口及试射记录。
