## 模块范围与验收

- **目标 / 需求**：F06；A18、A28。训练台、云上古城、霓虹天际、星际方舟共用配置与呈现；主题图必须具有实际不同的路线与平台组合，不能仅更换背景。
- **拥有路径**：`src/content/maps.ts`、`src/presentation/ArenaRenderer.ts`；建议新增地图数据文件、`tests/maps.test.ts`。应用 / 标题接入归集成者。
- **具体工作**：按 ID 注册四图；每图至少四个安全出生点、投放点与可达关系所需信息；背景、平台、边界提示根据当前地图；管理地图切换图形 / 文字资源。
- **集成契约**：碰撞、绘制、出生、投放、AI 使用同一个地图对象；菜单可以选默认预览，正式局必须选实际配置；首批保持 1280 × 720 逻辑尺寸。
- **验收**：四图出生点合法且主通路可用合法跳跃抵达；实体和单向平台表现可辨；切图后没有旧平台 / 文字残留；重赛 / 返回菜单正常；不得只给出矩形列表就声明实际可玩。
- **适中难度**：主题图主路内缘由下层平台接应，普通跑过头不应直接扣命，并能使用原有跳跃返回；外围悬空边缘仍允许真实弹丸连续击出向台内回跑的对手。失足恢复、单发救回与逐出生点全平台可达需同时通过；保留原有物理 / 武器参数。几何变化后同步投放点与真实台面高度。
- **依赖与边界**：与 T05 联测路线，与 T03 联测投放点。不要顺带加入移动平台 / 陷阱 / 破坏地形。
