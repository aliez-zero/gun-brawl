## 模块范围与验收

- **目标 / 需求**：F05、F11；A01、A22。把自由练习扩展成教学与可试枪环境。
- **拥有路径**：建议新增 `src/game/systems/TrainingSystem.ts`、`src/content/tutorial.ts`、`src/ui/training/`、`src/ui/encyclopedia/`、`tests/training.test.ts`。
- **具体工作**：移动、二段跳、穿台、命中、击出假人、投弹躲爆六项任务；可跳过 / 重新进入；选枪 / 补弹、静止 / 移动假人、训练内重置；图鉴显示真实配置并进入预选武器训练。
- **集成契约**：教学进度仅在合法事件后推进；完成标记交 T12；训练重置不复用正式结算；返回图鉴保留选择，正常练习入口可独立使用。
- **验收**：任务不被暂停、重置、保护命中错误推进；重置清空弹丸 / 炸弹 / 箱子 / 速度；仍无限命 / 时且不计战绩；六枪试用与图鉴参数一致。
- **依赖与边界**：没有真实炸弹 / 六枪时只能标阶段性完成；不能用按钮直接设置任务完成冒充教学判断。

## T08.2 当前切片（部分）

- `WEAPON_SLOTS` 固定六格：手枪 / 冲锋枪 / 步枪 / 霰弹枪 / 狙击枪 / 火箭筒。
- 训练场按 `Digit1`—`Digit6` 选择；`KeyboardInput.consumeWeaponSlot()` 只消费一次按下边沿。
- `BattleSimulation.selectTrainingWeapon(slot)` 仅在 `mode === 'training'` 生效，只改存活的人类玩家，通过 `equipWeapon` 满弹切换；不重置 `fireCooldown`，不直接改 DOM。
- 底栏显示 `1—6 试枪`，帮助弹窗说明；训练假人保持手枪。
- `tests/training.test.ts` 3 项：六格映射 / 补满、假人不被改 / 非法槽、非训练模式 no-op。
- 仍缺：静止 / 移动假人、训练内重置、图鉴、教程六任务、T12 完成标记。
