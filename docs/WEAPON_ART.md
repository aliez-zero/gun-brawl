# 武器外观设计

更新：2026-10-18（北京时间）。状态：**17 个型号 + 2 把终极武器已按参数化骨架重绘**，实战尺寸、对比度与轮廓差异同轮调整；数值平衡见 [武器型号与击退平衡](./WEAPONS.md)。

## 1. 这轮为什么要重画

实机截图里（`artifacts/training-shotgun.png`）武器是一条 4–8 px 高的深灰细棍：枪身与深色城墙糊在一起，看不出是哪种枪，也看不出握把、弹匣和枪口。诊断结果是三件事叠加：

1. **太细**：枪管 / 机匣在 160×80 的稿纸上只有 6–20 单位高，按 0.36–0.51 的显示比例缩到屏幕上只剩 2–7 px。
2. **太暗**：主体是 `#3f4d48` 一类的深灰绿，和四张地图的深蓝 / 深绿背景几乎同亮度。
3. **太空**：每把枪只占画布约 1/3 宽度，显示比例又被"不要挡住身体"限制，等于双重缩小。

## 2. 新方案

### 2.1 参数化骨架

`WeaponArt.ts` 不再"八家族画法 + 十七个覆盖层叠加"，改成一张 `SPECS` 表 + 一个 `drawGun`：

```ts
interface GunSpec {
  tip: number;                       // 枪口在 160 画布上的 x
  bore: number;                      // 膛线中心 y（默认 27–31）
  rec: [x, width, height];           // 机匣
  barrel: [height, yOffset];         // 裸露枪管
  stock: 'none' | 'wood' | 'poly' | 'skeleton' | 'thumbhole';
  mag:   'none' | 'box' | 'banana' | 'drum' | 'tube' | 'internal';
  guard?: 'wood' | 'poly';           // 护木
  scope?: [x, width, height];
  pump?: [from, to];
  double?: boolean; cone?: boolean; bipod?: boolean; belt?: boolean;
  brake?: 'ring' | 'brake' | 'bell' | 'plain';
  body / furniture / accent: string;
}
```

绘制顺序固定：枪托 → 枪管 → 护木 → 泵动 / 双管 → 机匣 → 抛壳口 → 弹匣 → 握把 → 镜筒 → 脚架 → 枪口装置 → 家族色条 → 型号细节 → 顶光体积层。所有部件共用一个 `slab()`（圆角 + 两点渐变 + 2 px 描边 + 顶部高光），所以 19 把枪看起来是同一套工艺。

### 2.2 三个可见修正

| 问题 | 做法 |
| --- | --- |
| 太细 | 机匣 22–36 单位高、枪管 7–24、**加护木盖住后段 55% 的枪管**；手内画布从 48–77 px 提到 58–96 px（显示比例 ×1.15–1.25） |
| 太暗 | 换高对比色板：枪钢 `#77898F`、亮钢 `#AFBFC2`、深钢 `#3A4850`、聚合物 `#4C5C53`、木 `#966034`；描边加深到 `#0A1116` 并加粗到 2 px |
| 太空 | 枪身向画布两端铺满（`tip` 138–156），图标裁剪框同步放大 |

护木是关键：没有它，任何长枪都是"机匣 + 一根针"；有了 18 单位高的护木，M416 / AKM / SCAR-L / Kar98k 在实战尺寸下能立刻和狙击、霰弹区分开。

### 2.3 家族识别色（保留）

| 家族 | 识别色 | 主体 / 家具 | 轮廓识别点 |
| --- | --- | --- | --- |
| 手枪 | 黄铜 `#E0B45A` / `#E8C56A` | 蓝灰钢 + 木握把 | 短滑套、无枪托、握把占重心 |
| 冲锋枪 | 青绿 `#4FC3B1` | 军绿聚合物 | 方盒机匣 + 直弹匣 + 短管 |
| 突击步枪 | 橙 `#F0A23A` | 沙 / 橄榄 + 木或聚合物护木 | 长机匣 + 护木 + 弹匣 + 枪托 |
| 霰弹枪 | 红 `#E05A4F` | 枪钢 + 木托 / 泵 | 粗管 / 双管 / 管式弹仓 |
| 狙击枪 | 紫 `#B48CE0` | 橄榄 + 合成托 | 长细管 + 顶置镜筒 + 拉机柄 |
| 火箭筒 | 警示黄 `#F2C94C` | 军绿管 + 木隔热套 | 粗管 + 锥形战斗部 |
| 加特林 | 灼橙 `#F2A23A` | 枪钢 + 弹箱 | 六管束 + 转轴环 + 弹带 |
| 重炮狙击枪 | 警示红 `#FF5D73` | 冷钢 + 深灰 | 超长粗管 + 大镜 + 制退器 + 脚架 |

识别色只出现在一条色条、准星或枪口环上，不整把染色。

## 3. 与弹道的对齐

`weaponMuzzle(id)` 的数值是按"画布上的枪口位置"换算的：

```
世界枪口 x = 手部基准(≈21.5) + (tip - 46) × 显示比例
世界枪口 y = 手部高度 - (46 - bore) × 显示比例
```

本轮改比例和 `tip` 后，`src/content/weapons.ts` 的 `MODEL_MUZZLE` / `FAMILY_MUZZLE` 已同步重算（手枪 36–43、冲锋枪 38–48、步枪 70–73、狙击 79–80、火箭 75–78、重炮 84）。子弹与枪口火光因此仍从画出来的枪口出生，而不是胸口。

> 约束：`tests/muzzle.test.ts` 会检查每把枪的枪口 x 在 25–100、y 在 −45–−30 之间，并断言弹丸 / 火光坐标等于 `weaponMuzzle()`。改 `tip` 或显示比例必须同步改这张表。

## 4. 图标与箱子

`createWeaponIconCanvas` 仍从同一份画布裁剪，只是 `ICON_BOUNDS` 按新枪身重新量过（手枪 78×54，长枪 156×60，狙击 / 重炮到 158×72）。HUD 与武器箱共用这一次裁剪，所以图标和手上模型永远是同一把枪。
