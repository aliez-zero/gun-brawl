# 武器外观设计（提案）

更新：2026-10-18（北京时间）。状态：**17 个型号已接入轮廓级几何、逐型号世界尺寸与 HUD 图标 / 图鉴卡片**。`WeaponArt` 以八家族轮廓为底，叠加各型号的枪管 / 枪托 / 弹匣 / 护木 / 双管 / 泵动 / 镜筒 / 火箭锥几何，以及色带与部件；`weaponDisplayScale` 以 160×80 逻辑稿为基准、除以 3 倍画布采样。朝左时同步镜像 origin，`WeaponLayer` 按 `definition.id` 创建独立纹理。当前五人及混搭由 `HumanoidRig` / `HumanoidView` 提供服装手臂、固定骨长与双手 IK，武器消费世界挂点，抑制 WeaponLayer 的旧前景手臂 / 小手路径。枪身保留体积渐变、顶部高光、枪管 / 导轨 / 弹匣 / 木纹 / 镜片 / 制退孔等细节。逐型号完整装填 / 火光贴图仍待，当前角色接口见 [R3 交接](./updates/2026-10-18-all-character-rigs.md)。

![武器侧视概念图](./assets/weapons-roster.png)

概念图为同一比例、程序化 2D 卡通侧视；右上角小框是约 58 px 的手内可读性检查。正式发布前如涉及商标，可替换型号名，外观语言不变。

## 1. 美术方向

- **轮廓优先**：先看枪种，再看型号。短枪靠弹匣 / 枪托区分，长枪靠枪管、瞄准镜、供弹方式区分。
- **低细节、高对比**：每把枪 2—4 个主色 + 1 条家族识别色；深色描边 1.2—1.5 px；不使用照片纹理、渐变噪点、真实商标或游戏素材。
- **手内可读**：角色高约 96 逻辑像素，手枪手内长度约 58—64 px，步枪 61—67 px；手枪不再缩到看不见，轮廓必须在不看 HUD 时也能区分。
- **HUD 可读**：32 px 图标只保留枪种剪影 + 家族色条，不画木纹、螺丝、小字。
- **同一朝向**：侧视朝右绘制，角色朝左时整体 `flipX`；枪口、弹匣、拉机柄的朝向不能靠文字说明。
- **不做写实**：木材用 2—3 条深色木纹表示，金属用一条高光表示，聚合物用大色块表示；保持和现有角色、地图同一套卡通语言。

### 轮廓速记

- **手枪**：短、没有枪托、握把占视觉重心。P92 圆、P1911 长、Deagle 大三角。
- **冲锋枪**：短枪管 + 大弹匣；UMP 方、Vector 楔、UZI 盒。
- **突击步枪**：长机匣 + 弹匣 + 枪托；M416 弧形弹匣、AKM 香蕉弹匣 + 木、SCAR 直弹匣 + 长导轨。
- **霰弹枪**：粗管；S686 双管、S1897 管式弹仓 + 泵、S12K 盒式弹匣。
- **狙击枪**：最长；Kar 木托无镜、M24 有镜、AWM 重管 + 大镜 + 制退器。
- **火箭筒**：最粗；RPG 锥形战斗部 + 木套、AT4 直管 + 肩托。

## 4. 枪口、后坐与换弹表演

下表是逐枪表演的设计目标，完整抽弹匣 / 拉栓 / 泵动尚未实现。当前运行时使用家族程序化火光、后坐及通用换弹倾斜 / 手臂动作，不能把表中时长当作已验收参数。

| 家族 | 枪口火光 | 后坐视觉 | 换弹动作 |
| --- | --- | --- | --- |
| 手枪 | 小型三尖星，0.06 s | 枪口上抬 2—3 px，握把后移 | 退弹匣 / 上弹匣，滑套后拉 |
| 冲锋枪 | 短锥形火光，0.04 s | 枪身后缩 2 px，轻微上抬 | 枪身侧倾，弹匣直插 |
| 突击步枪 | 三尖星 + 少量烟，0.05 s | 枪身后缩 3 px，枪口上抬 | 弹匣拍入 + 拉机柄 |
| 霰弹枪 | 宽扇形火光 + 烟环，0.09 s | 明显后缩，枪口大幅上抬 | S686 中折，S1897 泵动，S12K 换盒 |
| 狙击枪 | 细长条火光 + 侧向燃气，0.12 s | 最强后缩 / 上抬 | 拉机柄循环，弹匣更换 |
| 火箭筒 | 尾部燃气 + 前方烟团，0.18 s | 最大后坐，角色向后滑 | 后部装填，动作最慢 |

- 弹丸从 `weaponMuzzle(id)` 的逻辑枪口出生，已不再使用旧固定值 `27/-28`；R3 火光首次绘制按骨架世界挂点计算并快照，动画中可能与核心弹丸起点略有偏差。
- 后坐视觉只做 2—3 px 位移和 0.05—0.12 弧度旋转，不替代实际 `recoil` 物理冲量。
- 换弹动作不超过换弹时间；如果时间不够，优先保留“弹匣 / 枪机”关键帧，不补中间帧。

## 5. HUD 图标

- 32 × 32 图标：枪身用 1 条深色轮廓 + 2 个主色块，家族识别色放在枪口 / 弹匣底线。
- 手枪图标不需要画手；长枪把枪托缩到 2—3 px，保证枪管和弹匣仍可辨。
- 当前 HUD 的 `枪名 · 弹匣/备弹` 放在图标右侧；没有图标时不能只靠文字。
- 图标与手内模型共用同一份轮廓数据，不另画一套完全不同的形状。

## 6. 当前实现与后续

已接入：

- `src/presentation/WeaponArt.ts`：八家族（含加特林 / 重炮）及 17 个具体型号的 3× Canvas 纹理，握把为原点，枪口朝右；`weaponDisplayScale` 统一除以 3 倍采样。
- `src/presentation/WeaponLayer.ts`：每个 actor 一张独立武器 sprite，按 `ActorState.weapon.definition.id` 换纹理；`flipX` 跟随朝向，深度在角色之上、名字标签之下；换枪不重建角色图集。
- `HumanoidArt` / `HumanoidView` 共用部件和姿态；实战隐藏 `previewGun`，武器交给 `WeaponLayer`；菜单 / 编辑器显示真实手枪纹理。
- `src/presentation/FieldLayer.ts`：箱子 incoming / active / warning、武器图标、炸弹、爆炸圈；箱子图标复用同一套武器纹理。
- 数据来源是 `weapon.definition.id`，不是角色外观；17 型号轮廓、HUD / 图鉴、逐型号音高、投弹 / 拾取 / 爆炸音效和四图投放点均已接入。

后续：

1. 逐型号抽弹匣 / 装填 / 拉栓与完整专属动作。
2. 手绘火光贴图、真实音色素材。
3. 编辑器武器切换 / 时间轴；训练可通过图鉴选择具体型号，尚无实体武器墙。
4. 所有角色 / 地图组合的人工可读性与参考设备验收。

初版武器 / 场地层独立接入；后续 `ArenaRenderer` 已整合逐枪弹道、火光及全角色骨架，不能再按初版“不改渲染器”的范围理解当前接口。

## 7. 已采用的方向与后续决策

当前采用原创 2D 卡通、深色描边与程序化材质，17 型号有轮廓 / 尺寸差异，长枪允许超过 40 px；原型使用 P92 / M416 / AKM 等参考名。正式命名、实体武器墙及更写实的素材流程仍可后续讨论，不属于本轮已实现范围。

后续优先扩 `WEAPON_ART` 的 17 型号表，不改任何战斗数值。
