# 武器型号、弹夹与后坐力设计（提案）

更新：2026-10-17（北京时间）。状态：**设计提案，尚未改代码**。当前实现是 T01 的五把类别枪 + 总弹量 / 打空自动回手枪；本文提出 17 个具体型号和“弹匣 + 备弹 + 换弹”规则，落地前需要一次 T01 弹药模型重构。

参考方向：PUBG / CF 的型号熟悉度与角色分工，但数值按本项目 2D 平台乱斗重新设计，不照搬真实弹道、伤害或游戏素材。型号名仅作原型代号，正式发布前如涉及商标可替换为原创名。

## 1. 设计约束

- 本作没有生命值/护甲/爆头，**击退就是主要“伤害”**；表中“击退”是单发附加水平速度。
- 角色有 3 条命、180 秒、出界即失去一条命；武器需要围绕“推人下台”和“回台”设计。
- 当前引擎固定 60 Hz；弹丸使用扫掠碰撞；单向平台不挡弹。
- 基础手枪 P92 是复活 / 加时 / 打空后的兜底，**无限弹**，不参与掉落。
- 其余枪有弹匣、备弹和换弹；没有手动切枪、没有弹药箱、没有配件。
- 后坐力同时作用于持枪者：水平后坐把角色往射击反方向推，垂直后坐给一个小的向上抬升；没有随机首发散布（霰弹的固定扇形除外），保持可复现和公平。

## 4. 弹药与换弹规则

- **弹匣**：一个弹匣内的发数；**备弹**：身上额外的总发数；**总携弹 = 弹匣 + 备弹**。
- 拾取时弹匣和备弹都满；没有弹药箱，不补充备弹。
- 开火消耗 1 发弹匣；霰弹 5/6/4 丸也只扣 1 发。
- 弹匣为 0 时：
  - 按 R 手动换弹；
  - 或按住开火时自动进入换弹，延迟 0.2 秒开始，换弹时间见表。
- 换弹从备弹补满弹匣；备弹不足时补剩余数量。换弹期间不能开火，可以移动 / 跳跃，受击和出界正常。
- 弹匣和备弹都为 0 时自动回 P92；回退帧不额外生成 P92 子弹，保留当前换弹 / 射击节奏。
- 复活、加时、重赛重置回 P92，弹匣和备弹都重置；不继承上一把枪。
- 没有手动切枪；拾取新枪直接替换当前枪，旧枪丢失。基础 P92 无限弹，不换弹。
- HUD 显示 `枪名 · 弹匣/备弹`，例如 `M416 · 30/120`；换弹时显示进度。当前 HUD 只显示总弹量，需要扩展。

## 5. 后坐力与散布

- **水平后坐 X**：持枪者获得与射击方向相反的瞬时水平速度；可把自己推下台，也可用来位移。
- **垂直后坐 Y**：持枪者获得向上的小速度；P92 保持 0，其他枪 1—24，火箭最高。
- 所有枪继续使用当前 `MOVEMENT.impulseHalfLife = 0.3s` 的外力衰减；暂不做每把枪独立的恢复曲线，避免额外复杂度。
- 单发子弹不做随机首发散布；后坐力 + 射速就是主要控枪因素。只有霰弹使用固定扇形（±10°—±14°），不使用 `Math.random()`。
- 表中后坐力是“瞬时冲量”，不是屏幕震动；减少震动设置只影响镜头，不改变实际推力。
- 这套规则让高射速枪（Vector / AKM）更容易把自己推离平台，低后坐枪（UMP45 / M416）更稳；火箭后坐最大，发射前要留退路。

## 7. 与当前 T01 的差距

当前代码（T01）是：

- `WeaponDefinition.maxAmmo` 表示总弹量；`WeaponInstance.ammoRemaining` 直接递减；打空回 P92。
- 没有弹匣 / 备弹 / 换弹 / `reloadPressed`；HUD 显示 `枪名 · 总弹量`。
- 只有五把类别枪：手枪 / 冲锋枪 / 突击步枪 / 霰弹枪 / 狙击枪；火箭未注册。
- `Projectile` 已有二维 `velocity` / `impulse`，可支持霰弹扇形；`recoil` 只有水平 X。

要落地本设计，需要一次 **T01 弹药模型扩展**：

1. 类型：新增 `WeaponCategory`、17 个型号 ID、`WeaponDefinition.category / magazineSize / reserveAmmo / reloadTime / recoilY`；`WeaponInstance` 增加 `magazineRemaining / reserveRemaining / reloadRemaining`，替换 `maxAmmo` 总弹量语义。
2. 输入：`ActorInput.reloadPressed`（R），键盘 / AI / 默认值 / 测试全部接入；T06 负责改键和设置。
3. 战斗：开火扣弹匣；R / 自动换弹；换弹进度；弹匣 + 备弹耗尽回 P92；火箭走 T02 爆炸服务。
4. UI：HUD `弹匣/备弹` + 换弹进度；图鉴 / 训练试枪由 T08。
5. 数据：17 个型号注册表、权重、拾取入口（T03）；基础 P92 仍由 `startingWeapon` 兜底。
6. 测试：每个型号的弹匣 / 备弹 / 换弹 / 后坐力 / 霰弹 / 回退 / 复活重置；至少覆盖三把代表枪和全部类别。

这会改变 T01 的“总弹量自动回退”行为，不能在不改类型的情况下硬塞。建议作为一个新的 T01 扩展任务提交，不和当前已完成的五枪核心混在一起。
