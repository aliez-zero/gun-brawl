# 武器型号、弹夹与击退平衡

更新：2026-10-18（北京时间）。状态：**17 个具体型号已按 Gun Mayhem 的武器角色重做击退平衡**，并通过 246 项 / 27 文件测试、严格类型检查与生产构建；武器外观同轮重绘，见 [武器外观设计](./WEAPON_ART.md)。

本轮目标不是"加伤害"，而是让每把枪在**把对手推下台**这件事上有不同的时间曲线：全自动枪靠持续压制，霰弹靠贴身爆发，狙击 / 火箭靠单发位移。旧版霰弹一枪就能把 640 px 外的对手送出屏幕，火箭同理，而全自动枪 2–4 发就顶满 900 的冲量上限——两边都失去了区分度。

## 1. 平衡单位与推导

- 本作没有血量，**击退就是主要"伤害"**；淘汰只看是否出界。
- 击退是叠加在角色速度上的瞬时冲量，衰减半衰期 0.3 s（`MOVEMENT.impulseHalfLife`），所以**单发推距 ≈ 0.433 × 击退**（冲量对时间的积分）。
- 逻辑画面 1280 宽，**640 px 就是"半屏"**：从中间被推到边缘的距离。所有数值都对着这个尺子调。
- 冲量总矢量默认上限 900（`MOVEMENT.maxImpulse`）；`impulseCap` 让霰弹一次扣扳机的多颗弹丸、以及重炮 / 火箭能突破这个上限。
- 60 Hz 固定步长会量化射速：0.055 s 实际 4 帧一发（约 900 RPM），0.06 s 同样落到 4 帧。

三个观察口径（后两个由 `tests/knockback.test.ts` 守住）：

| 口径 | 定义 | 用途 |
| --- | --- | --- |
| 单发推距 | 一次扣扳机、目标静止时的最大水平位移 | 判断"这一下有多痛" |
| 持续推速 | 单发冲量 ÷ 间隔（含弹丸数） | 比较喷射型与单发型 |
| 对抗回跑 | 目标全速回跑、射手边走边打，3 秒内能否推过半屏 | 判断"能不能独立完成击杀" |

## 2. 设计结论

**只有全自动枪能在 3 秒内把全速回跑的对手推过半屏。** 单发重枪的冲量衰减比人跑得还快，所以狙击 / 霰弹 / 火箭是"边缘守卫"和"空中惩罚"工具：对手在边缘、跳跃中或刚从硬直恢复时才是它们的处决窗口。这条规则同时解释了为什么手枪是兜底武器——它能打断推进、能补刀，但推不动一个正在往回跑的人。

| 家族 | 单发推距 | 对抗回跑（3 s 半屏） | 定位 |
| --- | --- | --- | --- |
| 手枪 | 127–262 px | 否 | 基础兜底 / 补刀 |
| 冲锋枪 | 89–106 px | **是**（1.5–1.7 s） | 贴身压制，单发最轻 |
| 突击步枪 | 161–220 px | **是**（1.5 s） | 最强持续压制 |
| 霰弹枪 | **550–758 px / 一次扣扳机** | 否（射程只有 290–360 px） | 贴脸一枪推出 |
| 狙击枪 | 487–**762** px | 否 | Kar/M24 边缘处决，AWM 一枪推出 |
| 火箭筒 | **792–866 px** | 否（3–6 发、1.6–1.8 s 装填） | 爆心一发出屏，溅射也能击飞 |
| 加特林 | 39 px/发 | **是** | 200 发弹带的持续火力 |
| 重炮狙击枪 | 约 1200 px | 非设计用途 | 一发从中间送出屏幕 |

> 2026-10-18 第二轮（试玩反馈）：狙击单发从 850 / 950 / 1050 提到 **1150 / 1300 / 1450**，推距 487 / 550 / 614 px。此前一把狙击的单发推距还不如霰弹全中，试玩时"打中像没打中"。现在 M24 / AWM 在靠近边缘的位置可以单发处决。

### 3.8 弹速分档（2026-10-18 第三轮）

弹速不再只是"每把枪一个数"，而是按枪种分档的可调轴。统一的度量是**横穿 1280 px 屏幕需要多少秒**——它直接决定玩家要不要打提前量。

| 档位 | 弹速 px/s | 横穿屏幕 | 型号 |
| --- | --- | --- | --- |
| 重炮 | 3600 | 0.36 s | 重炮狙击枪 |
| 狙击 | 3000–3400 | 0.43–0.38 s | Kar98k 3000 / M24 3200 / AWM 3400 |
| 步枪 | 2000–2200 | 0.64–0.58 s | AKM 2000 / M416 2100 / SCAR-L 2200 |
| 加特林 | 2000 | 0.64 s | 加特林 |
| 手枪 | 1550–1900 | 0.83–0.67 s | P92 1600 / P1911 1550 / Deagle 1900 |
| 冲锋枪 | 1450–1600 | 0.88–0.80 s | UZI 1450 / Vector 1500 / UMP45 1600 |
| 霰弹 | 1450–1600 | 0.88–0.80 s | S1897 1450 / S686 1500 / S12K 1600 |
| 火箭 | 720–800 | 1.78–1.60 s | RPG-7 720 / AT4 800 |

设计含义：

- **步枪与狙击几乎不需要提前量**，看到人就打；狙击弹速是步枪的 1.4–1.6 倍。
- **冲锋枪和霰弹仍要靠身位**，0.85 s 的飞行时间意味着横向跑动会吃掉一部分命中。
- **火箭保持最慢**，1.6–1.8 s 的飞行时间是有意为之：能被看见、能被躲开。
- 弹道仍是线段扫掠碰撞，3400 px/s 下每帧约 57 px，不会穿人。
- 曳光长度现在随弹速缩放（`ArenaRenderer` 的 `trailStyle`），所以"更快的子弹看起来更长更亮"。

## 4. 弹药与换弹规则（未变）

- 拾取时弹匣和备弹都满；开火消耗 1 发弹匣；霰弹多丸也只扣 1 发。
- 弹匣打空自动换弹，备弹为 0 才回退到无限手枪；P1 `R` / P2 小键盘 `2` 可手动换弹。
- 换弹期间不能开火，可以移动 / 跳跃，受击和出界正常。
- 复活、加时、重赛都重置回 P92，不继承上一把枪。

弹药经济在 2026-10-19 按试玩反馈重做：此前"打光一整个携弹也推不动回跑对手"——S686 满携弹只能推 205 px、S12K 336、RPG 339、P1911 616（过线要 640 px）。原因是**换弹期间对手正好把位移跑回来**。这一轮同时加弹量、砍换弹时间，并收紧霰弹散布。

### 3.9 携弹承诺：一个满携弹必须能推出一个人

`tests/weapon-loadout.test.ts` 把这条写成硬约束：**每把标准枪，从满弹匣 + 满备弹打到回退手枪为止，必须能把一个全速回跑的对手推过 640 px（半屏）**；同时换弹时间 ≤1.8 s。

注意这个口径在单发威力大幅提高后不再是"越大越强"的线性指标——把对手一枪打飞出射程后，后续子弹反而打不中。当前最低的三个是 S12K（951 px）、AT4（1 721 px）、RPG-7（1 802 px），单发都已经能一击推出，数字低只是"目标被推远了、追不上"。

换弹时间统一压在 1.0–1.8 s（原 1.4–3.0 s），因为对手 300 px/s 的跑动意味着每多 1 秒装填就白送 300 px。

## 5. 与 Gun Mayhem 的对应

原版（Gun Mayhem / Gun Mayhem 2）**没有公开的逐枪数值表**；本项目的调研文档一贯记录"原版精确数值未知"（见 [功能调研](./RESEARCH.md) 第 7 节）。因此本轮不照搬数字，而是按原版被公开描述的武器角色定标：

- 散弹枪是"近距离重击退"（官方商店页与 wiki 的描述一致）→ 单发推距最高、射程最短、节奏最慢。
- 狙击是"精准击退"→ 单发高、射速低，靠边缘与空中窗口。
- 火箭筒是"范围压制"→ 爆炸半径 + 爆心高冲量，但只有 3–4 发。
- 全自动是"持续火力"→ 单发最低、持续最高，靠弹量和射速取胜。
- 加特林在原版以 150 发弹链和最高持续火力著称 → 本作 200 发、单发 90。

型号名（P92 / M416 / AKM 等）仍是原型代号，正式发布前需替换为原创名。

## 7. 验证

本轮实际执行（2026-10-19）：

- `pnpm test`：**261 项 / 30 文件通过**。
- `pnpm typecheck`、`pnpm build`：通过（Phaser 单独分包）。
- `tests/knockback.test.ts` 守住单发推距排序（手枪 < 步枪 < 狙击 < 火箭）、霰弹是一次扣扳机 240–520 px 而不是出屏、全自动才能把全速回跑的对手推过半屏。
- `tests/weapon-loadout.test.ts` 守住"一个满携弹必须能推出一个人"（≥640 px）与换弹 ≤1.8 s。
- `tests/projectile-speed.test.ts` 守住弹速分档与"火箭必须慢到能躲"。
- `tests/explosions.test.ts` 守住炸弹 1.1 s 引信、双方都受伤、推力方向沿炸弹→人物。
- `scripts/weapon-visuals.mjs` 产出 `artifacts/weapons-in-hand.png`（17 型号 + 2 终极的实战尺寸与放大对照）。

## 8. 仍待

1. 人工逐枪试玩手感（尤其 S686 / S1897 的双管与泵动节奏、AT4 的 5 发是否够用）。
2. 全自动枪的持续压制在真实对局里是否过强：本轮只验证了"能推过半屏"，没有多轮真人样本。
3. 死亡 / 复活后的武器归属、以及是否增加弹药箱。
4. 型号名替换与逐枪音色素材。
