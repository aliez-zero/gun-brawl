# 武器型号、弹夹与后坐力设计

更新：2026-10-18（北京时间）。状态：**17 个具体型号已实现并通过 188 项 / 20 文件武器改动集回归**。P92 + 16 个标准型号拥有独立弹匣 / 备弹 / 换弹 / 后坐参数与定位；八类别名保留给训练 1—8 与旧存档；逐型号轮廓 / 尺寸 / 外观、HUD 名称 / 图标和射击 / 换弹音高已接入。

本轮按 CF 的枪械分工重做：P92 是 360 / 0.30 s 副武器，单发低于步枪；P1911 快速点射、Deagle 700 单发重手炮；UMP45 600 RPM 稳健、Vector 1091 RPM 极速、UZI 857 RPM 弹幕；M416 667 RPM 均衡、AKM 600 RPM 单发 700、SCAR-L 600 RPM 远距；S686 / S1897 / S12K 全中 900 / 1120 / 725；Kar98k / M24 / AWM 单发 1150 / 1300 / 1500；RPG-7 / AT4 爆心 900 / 1100。图鉴显示定位、单发 / 持续威力条，实测推距见 [平衡交付](./updates/2026-10-18-weapon-balance.md)。

参考方向：PUBG / CF 的型号熟悉度与角色分工，但数值按本项目 2D 平台乱斗重新设计，不照搬真实弹道、伤害或游戏素材。型号名仅作原型代号，正式发布前如涉及商标可替换为原创名。逐型号的侧视轮廓、配色、手内尺寸与 HUD 图标规则见 [武器外观设计](./WEAPON_ART.md) 和 [侧视概念图](./assets/weapons-roster.png)。

## 1. 设计约束

- 本作没有生命值/护甲/爆头，**击退就是主要“伤害”**；表中“击退”是单发附加水平速度。
- 角色有 3 条命、180 秒、出界即失去一条命；武器需要围绕“推人下台”和“回台”设计。
- 当前引擎固定 60 Hz；弹丸使用扫掠碰撞；单向平台不挡弹。
- 基础手枪 P92 是复活 / 加时 / 打空后的兜底，**无限弹**，不参与掉落。
- 其余枪有弹匣、备弹和换弹；没有手动切枪、没有弹药箱、没有配件。
- 后坐力同时作用于持枪者：水平后坐把角色往射击反方向推，垂直后坐给一个小的向上抬升；没有随机首发散布（霰弹的固定扇形除外），保持可复现和公平。

## 4. 弹药与换弹规则

- **弹匣**：一个弹匣内的发数；**备弹**：身上额外的总发数；**总携弹 = 弹匣 + 备弹**。
- 拾取时弹匣和备弹都满；没有弹药箱，不补充备弹。
- 开火消耗 1 发弹匣；霰弹 5/6/4 丸也只扣 1 发。
- 弹匣为 0 时：
  - P1 按 R / P2 按小键盘 2 手动换弹；
  - 或按住开火时，在射速冷却后自动进入换弹；当前类别级实现没有额外的 0.2 秒延迟。
- 换弹从备弹补满弹匣；备弹不足时补剩余数量。换弹期间不能开火，可以移动 / 跳跃，受击和出界正常。
- 弹匣和备弹都为 0 时自动回 P92；回退帧不额外生成 P92 子弹，保留当前换弹 / 射击节奏。
- 复活、加时、重赛重置回 P92，弹匣和备弹都重置；不继承上一把枪。
- 没有手动切枪；拾取新枪直接替换当前枪，旧枪丢失。基础 P92 无限弹，不换弹。
- 当前 HUD 已显示 `枪名 · 弹匣/备弹`，例如 `突击步枪 · 30/90`；换弹时显示倒计时 `换弹 1.2s`。17 型号阶段再补逐枪进度条 / 动画。

## 5. 后坐力与散布

- **水平后坐 X**：持枪者获得与射击方向相反的瞬时水平速度；可把自己推下台，也可用来位移。
- **垂直后坐 Y**：持枪者获得向上的小速度；P92 保持 0，其他枪 1—24，火箭最高。
- 所有枪继续使用当前 `MOVEMENT.impulseHalfLife = 0.3s` 的外力衰减；暂不做每把枪独立的恢复曲线，避免额外复杂度。
- 单发子弹不做随机首发散布；后坐力 + 射速就是主要控枪因素。只有霰弹使用固定扇形（±10°—±14°），不使用 `Math.random()`。
- 表中后坐力是“瞬时冲量”，不是屏幕震动；减少震动设置只影响镜头，不改变实际推力。
- 这套规则让高射速枪（Vector / AKM）更容易把自己推离平台，低后坐枪（UMP45 / M416）更稳；火箭后坐最大，发射前要留退路。

## 7. 当前实现与剩余

已实现：

- `src/content/weapons.ts` 的 `ARMORY_WEAPONS` 为 17 型号注册表；`WEAPON_MODELS` 保存 16 个型号，P92 为 `BASIC_PISTOL`。
- `WeaponDefinition.maxAmmo` / `reserveAmmo` / `reloadTime` / `recoil` / `recoilY` 逐枪独立；`CombatSystem` 同时施加水平与垂直后坐。
- 八类别名仍可用于训练 1—8、旧存档和既有测试；拾取 / HUD / 图鉴使用具体型号名。
- `STANDARD_DROP_POOL` 使用 16 个标准型号并过滤两类终极；图鉴 17 张卡可直接预选任意型号进入训练。
- `WeaponArt` 以家族轮廓 + **型号级几何**（枪管 / 枪托 / 弹匣 / 护木 / 双管 / 泵动 / 镜筒 / 火箭锥）和色带绘制手内与 HUD 图；`weaponDisplayScale` 让手枪 / 冲锋枪 / 步枪 / 狙击 / 火箭的世界尺寸拉开。
- 图鉴显示定位、单发威力条和持续威力条；`weaponBurstImpulse` / `weaponSustainedImpulse` 作为同一套比较口径。
- `SoundEffects` 按 `weaponId` 使用逐型号射击 / 换弹音高。
- `tests/weapons-models.test.ts` 6 项覆盖注册表、弹量 / 换弹、定位与威力排序、训练预选、支撑手和投放池。

2. 逐型号真实音色素材；当前为 WebAudio 合成音高。

## 8. 已确认与待确认

已确认：

1. 默认池加入 P1911 / Deagle（当前权重 8 / 4）；训练与图鉴均可单独选择。
2. 垂直后坐力实际作用于角色（`CombatSystem` 的 `recoilY`），不是镜头效果。
3. 换弹保持“R 手动 + 空仓按住开火自动”，不额外加 0.2 秒延迟。
4. 暂不增加 DMR / 轻机枪家族；保持六类 + 终极。

待确认：

1. 型号名 P92 / M416 / AKM 等参考名是否在正式发布前换成原创名。
2. 逐型号手绘换弹 / 音色素材是否进入下一轮美术与音频预算。
3. 17 型号的最终数值平衡需人工逐枪对局确认。

17 型号已落地；后续继续按“逐枪手绘动作 → 音色素材 → 人工平衡”推进，并保留当前 P92 手感作为回归基线。
