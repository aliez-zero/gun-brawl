# T01 / T10 追加：CF 式威力分层、人枪比例与轮廓重做

更新：2026-10-18（北京时间）。触发原因：用户反馈“枪的模型看起来都差不多”“人枪比例不对”“击退距离还是有问题，参考 CF 的枪械威力设计”。

## 问题定位

- 17 个具体型号进入投放池后，参数仍是早期设计值，**单发击退低于手枪**：
  - M416 85 / AKM 120 / SCAR-L 95，而 P92 480；
  - 冲锋枪 32—100；
  - Kar98k 360 / M24 380 / AWM 500；
  - RPG-7 爆心 330 / AT4 360。
- 所有枪共用 0.55—0.80 世界缩放；角色约 96 px 高，AWM 却有 121 px，像“人物拖着一根长棍”。
- 狙击 / 霰弹的单发冲量被 `maxImpulse 900` 截断，Kar98k、M24、AWM 实测都只推 373 px，面板差异没有意义。

## 本轮调整

### 1. 按 CF 分工重做单发击退

CF 本身没有击退，本次只借鉴它的枪械分工：**手枪是副武器、冲锋枪高射速、步枪 3—4 发、霰弹贴脸、狙击一发**；把“伤害”翻译成本作的“出界推力”。

### 1.5 修复“面板射速不等于实际射速”

- 60 Hz 固定步长下，旧逻辑把冷却重置为整数帧，0.055 s 的 Vector 实际 4 帧一发（900 RPM），0.075 s 的 UMP45 也是 5 帧（720 RPM）。
- 已把 M416 对齐到 5 帧（0.0833 s / 720 RPM），UMP45 5 帧（720 RPM），UZI 4 帧（900 RPM），Vector 3 帧（1200 RPM）；冲锋枪现在确实比步枪快。
- 新增回归：0.5 s 内 Vector > UZI > UMP45 的发数；不会出现“表里 1091、手感 900”的落差。
- 注意：极快枪仍按 60 Hz 整帧结算，表内 RPM 是实际有效值，不是未经量化的理论值。

### 2. 修复冲量截断

- 原先所有弹丸默认被 `MOVEMENT.maxImpulse = 900` 截断，AWM 1500 和 Kar98k 1150 实际一样。
- `CombatSystem` / `ExplosionSystem` 现在按“至少完整保留该发弹丸冲量”设置上限，狙击和霰弹的层级恢复。
- 三把霰弹分别设置整发上限 S686 2100 / S1897 2800 / S12K 1800，避免多颗弹丸逐颗累计时又被 900 截断；RPG-7 / AT4 爆心 2400 / 2800，直击可以把目标击出 1280 宽的屏幕。
- 新增回归：在平地、目标 x=750、屏幕宽 1280 的条件下，S686 / S1897 / S12K / 通用霰弹 / RPG-7 / AT4 / 通用火箭的 2.5 s 推距都越过右边缘；重炮保持终极定位（3400，上限 4000）。
- **打空自动换弹**：最后一发射出的同一帧若备弹 > 0，会立即触发 `reload-start`，不需要松开或再次按开火；备弹为 0 才回退手枪。新增回归覆盖“松开扳机也能完成换弹”。

### 3. 人枪比例与握持

- **根因**：武器画布是 `160×80 × SAMPLE(3) = 480×240`，但世界缩放直接用了 0.33 等“160 逻辑尺寸”的值，实际渲染约 160 px。现在 `weaponDisplayScale` 统一除以 `SAMPLE`。
- 角色贴图约 96 px 高；逐枪世界尺寸改为：
  - 手枪 0.27—0.32 ≈ 43—51 px；
  - 冲锋枪 0.30—0.34 ≈ 48—54 px；
  - 步枪 0.38—0.42 ≈ 61—67 px；
  - 霰弹 0.38—0.42 ≈ 61—67 px；
  - 狙击 0.47—0.48 ≈ 75—77 px；
  - 火箭 0.45—0.47 ≈ 72—75 px；
  - 加特林 / 重炮 0.50—0.51 ≈ 80—82 px。
- AWM 从 121 px 缩到 77 px（约角色高度的 80%），步枪约 65%，手枪约 45%；握把前移到角色胸前外侧，枪管伸出身体，避免被躯干吞掉。
- 之前按“160 逻辑稿”估算为 54 px，但忘记画布是 3 倍采样，实际渲染 160 px；现在统一按 3 倍采样折算，粗枪约 61—77 px，细枪约 43—54 px。
- **左右镜像修复**：Phaser 的 `flipX` 绕帧中心镜像，不会自动把原点也镜像。朝左时把 origin 改成 `1 - gripX/width`，握把才会始终在手上；否则枪托会跳到身体另一侧，看起来像换了模型。
- 武器层固定在角色前方（depth 3），左右轮廓严格镜像；新增**前景持枪手臂**：肩→肘用袖子色，肘→腕用肤色，带描边、肘部和手部关节点；长枪再加一条胸→支撑手的支撑臂。握把小手（depth 3.4）和放大到 0.64 的支撑手随枪身旋转。
- 武器贴图增加自动箱体明暗渐变、顶部高光、整体受光体积层，以及枪管高光、导轨槽、弹匣筋、木纹、瞄准镜镜片、枪口制退孔等细节；不再是纯色块。

### 4. 模型区分与图鉴

- 保留 16 个型号的轮廓级几何（枪管 / 枪托 / 弹匣 / 双管 / 泵动 / 镜筒 / 火箭锥）与型号色带。
- 图鉴 17 卡带同尺寸轮廓、定位、单发 / 持续威力条；尺寸只影响世界内比例，不影响图标辨识。
