# T01 / T10 追加：逐枪威力与轮廓重做

更新：2026-10-18（北京时间）。触发原因：用户反馈“枪的模型看起来都差不多，一点区分度也没有”，同时实战中具体型号的击退明显低于类别枪，导致拿到任何长枪都像同一把弱枪。

## 问题定位

- 17 个具体型号已替代类别枪进入投放池，但参数仍是早期设计值：
  - M416 85 / AKM 120，而类别步枪 520；
  - Kar98k 360 / M24 380 / AWM 500，而类别狙击 1100；
  - RPG-7 爆心 330 / AT4 360，而类别火箭 650；
  - 冲锋枪 32—55，持续压制也低于基础手枪。
- 外观虽有家族轮廓和色带，但所有枪共用同一世界缩放，近距离看仍是一排相似的长条。
- 图鉴只显示“击退”单值，没有单发 / 持续威力的比较口径。

## 本轮调整

### 1. 逐枪定位与威力

| 定位 | 型号 | 关键差异 |
| --- | --- | --- |
| 基准 | P92 | 480 / 0.28 s，无限弹 |
| 快速点射 | P1911 | 340 / 0.20 s，持续略高于 P92 |
| 重手炮 | Deagle | 760 单发，0.46 s，高后坐 |
| 稳健压制 | UMP45 | 205 / 0.115 s，单发高于 UZI |
| 极速爆发 | Vector | 100 / 0.055 s，持续最高 |
| 弹幕压制 | UZI | 130 / 0.075 s，弹量最多 |
| 均衡步枪 | M416 | 210 / 0.115 s，低后坐 |
| 重击步枪 | AKM | 285 / 0.13 s，高单发 / 高后坐 |
| 远距精准 | SCAR-L | 230 / 0.12 s，920 px 最远 |
| 双管爆发 | S686 | 120 × 6 = 720 / 0.42 s |
| 泵动重击 | S1897 | 145 × 7 = 1015 / 0.8 s |
| 半自动霰弹 | S12K | 105 × 5 = 525 / 0.45 s |
| 精准狙击 | Kar98k | 900 / 1.0 s |
| 快速狙击 | M24 | 980 / 0.9 s |
| 重狙 | AWM | 1250 / 1.2 s，1450 px |
| 范围重击 | RPG-7 | 爆心 720 / 边缘 180，半径 155 |
| 高爆重击 | AT4 | 爆心 850 / 边缘 220，半径 140 |

具体数值以 `src/content/weapons.ts` 和 [WEAPONS.md](../WEAPONS.md) 为准；类别枪保留给训练 1—8，不参与投放。

### 2. 模型区分

- `WeaponArt` 增加 16 个型号的**轮廓级几何**：长短枪管、枪托、弹匣、护木、双管、泵动、镜筒、火箭锥。
- `weaponDisplayScale` 逐型号设置世界尺寸：手枪 0.45—0.54、冲锋枪 0.46—0.50、步枪 0.62—0.65、狙击 0.70—0.76、火箭 0.70—0.72、加特林 / 重炮 0.78—0.80。
- 支撑手位置随逐型号缩放同步，避免大手 / 小手错位。
- 17 型号武器墙：`artifacts/weapon-wall.png`。

### 3. 图鉴可读性

- 每张卡显示定位（快速点射 / 重击步枪 / 重狙等）。
- 新增“单发威力”和“持续威力 / s”两条比例条，统一用 `weaponBurstImpulse` / `weaponSustainedImpulse` 计算；霰弹按全中丸数、火箭按爆心。
- 图鉴截图：`artifacts/armory-17.png`。
