# T04 · 更容易击出与淘汰节奏

用户明确方向：**更容易掉下去，加快淘汰节奏**。本次接着 [差异化地图布局](./2026-10-17-distinct-map-layouts.md) 调整，原记录中的宽底台数值以本文为准。

## 地图变化

之前低层平台覆盖了大量上层缺口，被打离平台后经常自动落到下一层。现在将退路改为局部回台点，内侧也形成真正能扣命的落空区。

| 地图 | 中央底台调整 | 其余变化 |
| --- | --- | --- |
| 古城 | 庭院宽 500 → 260，位于 x510..770 | 两侧堡垒内缘与庭院相距 140；断墙、屋顶和塔冠适度收窄，保留双塔登高路线 |
| 都市 | 维修通道宽 610 → 260，位于 x510..770 | 收窄主屋顶和管道，楼间不再被底部大平台普遍接住；广告牌 / 步道保持可跳转 |
| 飞船 | 气闸宽 430 → 200，位于 x540..740 | 反应堆宽 400 → 280，泊台宽 265 → 230；气闸只覆盖核心下方，泊台与核心之间留空 |
| 训练台 | 保持原样 | 继续作为高容错训练及武器 / 移动基线 |

三张主题图仍各有四个安全出生点，所有平台均可用正常移动、跳跃、二段跳抵达。不跳直接朝中央平跑会掉入缺口；这是本次有意增加的风险。

美术与风险对齐：悬空危险边缘标出古城刻痕或都市 / 飞船警戒条；提示依据实际平台与下层接台推导，位于台面亮线下。古城远景桥面与都市远景楼群淡化，飞船底部贯通的装饰地板移除，避免误认为缺口下有地面。

菜单角色站位改为在附近实际平台的安全区域中选点；缩窄平台后仍正确落脚。选图文案提醒缺口坠落与穿台落点。

## 行为验收

新增 `tests/map-combat.test.ts` 的 15 项回归，配合原 24 项路线测试：

- 6 处关键内侧战区：古城西 / 东堡垒、都市西楼 / 中市场楼、飞船左 / 右泊台。
- 双方位于真实台面，受击者起始距内侧边缘 70，且已朝台内全速移动。持续射击时受击者每帧均向台内回跑，包括掉落期间，不靠停步挨打或反向自摔通过测试。
- 这些固定场景均在 **3 次真实手枪命中、1.30–1.40 秒**后从受打内侧缺口坠落扣命，击出归因正确；检查在首次扣命立刻停止，不允许复活位置掩盖失败。
- 单发场景使用相同起点和正常回跑，到安全区后刹车，6 处均能保住生命并回到原台面。
- 三张主题图各验证从出生点不跳平跑会真实坠落扣命；逐出生点全平台互达、合法气闸回台、6 种 AI 气闸恢复仍通过。

这是固定边缘场景的结果，不是整局平均淘汰时长；不同站位、跳跃躲避、AI 策略与其他武器仍有各自结果。
