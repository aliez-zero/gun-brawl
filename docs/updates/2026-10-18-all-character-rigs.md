## 剩余边界

仍为 TS + Phaser 的原创 Canvas / Path2D 2D 分层美术，没有接入 Spine、3D、外部美术资源或真实布料物理。角色的身高和动作不改变 36 × 52 命中盒。长枪向内收和动画倾斜只改变表现，核心弹丸出生点仍与动画挂点可能有少量位置差，不能通过修改骨长消除。

逐型号抽弹匣 / 装填 / 拉栓、专属胜利动作 / 表情、武器切换预览 / 时间轴、全部颜色与地图组合的人工验收及参考硬件性能仍待后续。新增服装应独立实现美术函数，复用共用人体插槽和握点；不要重新引入一套会修改对局坐标的骨架物理。
