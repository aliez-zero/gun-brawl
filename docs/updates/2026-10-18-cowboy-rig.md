## T10-R2：按“更像人”的反馈修正

本次接续同一工作区的未提交成果，Git 基线 `3cf8707`。首版出现了两条腿向相反方向屈膝、长枪支撑手臂变长、帽檐遮眼、头大腿短和关节像拼装件的问题。首轮握点 / 生命周期检查通过，不能代表人体与动作自然；本次增加了可对照的姿态检查。

- **固定人体尺寸**：大腿 15.5、小腿 14.5、上臂 16.5、前臂 15.5，单位为角色局部坐标。所有枪械与跑跳 / 受击 / 换弹共用相同骨长；双膝向前弯曲，踝关节连接靴子，靴底在踝点下方 5 个单位。
- **轮廓重绘**：抬高髋部，缩小头部和帽檐，露出额头、双眼、下颌与脖子；收窄躯干，柔化大腿 / 小腿 / 肩肘的重叠轮廓，减轻描边和附件摆动。
- **自然步态**：跑步采用 58% 支撑、42% 抬脚回摆，加入缓动；跳跃收腿与落地缓冲保留固定骨长，不通过缩放肢体制造动作。
- **长枪持握**：枪柄向内收 9 个单位，支撑手选择机匣下方可触及的位置；换弹时在胸腹前收手，不再向枪管前端拉长手臂。枪口火光跟随实际渲染挂点，生成后固定在开火位置。
- **缓存与证据**：牛仔部件 key 为 `cowboy-rig-v2`，身体图集 key 为 `look-v4`；新增 `scripts/character-anatomy-visuals.mjs`，同时检查 20 种站立 / 跑动 / 长枪 / 跳跃 / 换弹姿态以及 1× 尺寸。

局部美术与姿态不参与碰撞。长枪向内收属于表现层调整，核心弹丸出生位置与命中规则未调整；动画挂点与核心出生点仍可能有少量位置差。其余四种风格与跨服装组合继续沿用原有图集，本次没有把它们迁移成同一个牛仔身体。

## 实际交付

- **牛仔造型**：重做头身比例、三分之四面部、卷曲帽檐、领巾、长衣下摆、徽章、皮带扣、枪套、靴子与腕带。用曲线轮廓、宽明暗面和少量缝线区分皮革、布料、黄铜与皮肤。
- **连续骨架**：18 个身体 / 服饰部件独立变换，另有一个仅在预览中显示的手枪部件。运行时不再切换整张身体帧，跑动步相、呼吸、上升 / 下落 / 二段跳、落地压缩、后坐与换弹可同时存在。
- **手枪与长枪持握**：两段骨骼 IK 计算肘关节，触发手跟随枪柄，长枪支撑手跟随机匣下方握点；换弹时支撑手向弹匣区域移动。角色输出世界坐标武器挂点，真实 `WeaponLayer` 消费同一位置和角度，牛仔不再叠加旧手臂。
- **附件动作**：衣摆、围巾和帽檐采用与身体错开的相位摆动，属于程序化次级动作，不是布料物理。暂停冻结，复活重置步相，重赛销毁旧部件。
- **外观预览**：五种风格均可选择待机 / 跑动 / 跳跃 / 换弹、切换左右朝向，并查看 1× 尺寸。牛仔大图、缩略图、菜单和实战使用同一套部件绘制。关闭、反复刷新和 UI 销毁都会清理预览 RAF、事件和观察器。

牛仔骨架条件为 `style === 'cowboy' && outfit === 'cowboy'`，该身体支持全部六种头饰状态、八配色和三肤色。其他四位角色及跨风格服装组合继续使用原有 22 帧图集，所有混搭仍可选择和保存。不能据此宣称五人骨架全部完成。

## 技术与接入

仍使用 TypeScript + Phaser 3。美术是 Canvas / Path2D 原创绘制，烘焙为可共享的部件纹理；**这是自定义轻量 2D 骨架，不是 Spine 接入，也不是 3D 模型**。没有增加 npm 依赖、素材下载或编辑器授权要求。

| 文件 | 职责 |
| --- | --- |
| `src/presentation/characters/RigMath.ts` | 二骨骼 IK、旋转与局部坐标变换；不可达目标在最大可达范围停止 |
| `src/presentation/characters/CowboyRig.ts` | 纯姿态采样、步相 / 呼吸时钟、附件相位、握点和世界挂点 |
| `src/presentation/characters/CowboyArt.ts` | 分层形状、材质、头饰、部件图集和 Canvas 组合绘制 |
| `src/presentation/characters/CowboyView.ts` | Phaser Image 部件、镜像、层级、透明度与对象销毁 |
| `CharacterPainter.ts` / `CharacterArt.ts` | 牛仔样板分流、其他外观保留；身体图集 key 升为 `look-v4` |
| `ArenaRenderer.ts` | 选择骨架或旧图集、冻结时钟、复活清理、共享纹理缓存及 `weaponMounts` |
| `WeaponLayer.ts` / `ArenaScene.ts` | 新增可选挂点参数并串行传递；旧角色继续原有调用路径 |
| `ui/appearance/AppearanceMotionPreview.ts` | 独立预览控制、1× 对照、RAF 生命周期 |
| `AppearanceEditor.ts` / `appearance.css` / `GameUI.ts` | 预览入口、桌面 / 窄屏排版及 UI 销毁钩子 |

`ArenaRenderer.draw()` 必须先于 `WeaponLayer.draw(state, alpha, arenaView.weaponMounts)`。挂点每次绘制清空再生成，只包含当前存活的骨架角色。`WeaponMount` 为世界坐标 `{ x, y, rotation, alpha }`；骨架内部坐标始终朝右，世界挂点和所有部件一起镜像，武器仍保留原有镜像原点修正。

`supportGrip()` 是 160×80 逻辑美术坐标，武器 Canvas 为 3× 采样，因此骨架转换握点使用 `weaponDisplayScale(id) * 3`，不能再次缩小三倍。`cowboySupportGrip()` 在机匣下方选择可触及的支撑点，最多在枪柄前方 8 个角色单位，不直接使用原先较远的前握点。角色世界坐标仍为脚底中心；各部件以对应关节为局部原点，不参与命中或地形碰撞。

每套牛仔部件图集为 1200×1152，RGBA 原始像素约 5.27 MiB；最多 8 套外观缓存与旧图集共用额度。旧图集单套约 6.33 MiB。上述均是尺寸推算，不是总显存 / 堆内存测量。双牛仔验证场景中对象总数保持 45（含世界、名字和武器）；没有做参考 GPU 性能验收。
