## 实际交付

### 六项训练任务

训练面板显示六项任务和完成数：

1. 移动约 0.6 秒
2. 空中二段跳
3. 单向平台向下穿台
4. 命中训练假人
5. 击出训练假人
6. 投出一枚炸弹

任务只从合法输入和 `hit` / `ringout` / `bomb` 事件推进，UI 按钮不能直接勾选。暂停不推进；完成后写入现有 v1 存档，刷新后保留。

### 训练环境

- 训练模式固定使用训练台，不再被菜单选图带到主题地图；之前实际训练背景会跟随 `selectedMapId`，本轮修正。
- 训练假人默认移动巡逻，可在面板切换“移动中 / 静止”；假人不射击，仍可被命中 / 击出。
- “重置训练”清空弹丸、炸弹、箱子和速度，回到 3 秒倒计时；保留已完成任务和当前试枪。
- 1—8 试枪、弹匣 / 备弹补满保持可用；假人不受选枪影响。

### 武器图鉴

- 菜单新增“武器图鉴”，读取八把枪的真实定义：弹匣 / 备弹、换弹、射速、射程、击退、弹丸 / 散布、爆炸半径。
- 每张卡可直接“用此枪训练”：进入训练台后通过同一 `selectTrainingWeapon` 入口预选，不直接改角色状态。
- 图鉴在桌面 1440 与 560 以下单列布局可用。
