## 2. 功能 / 平衡

- **4 真人同屏**：当前设计为 2 名本地玩家 + 最多 2 AI，仅两个本地人类输入槽；4 真人需要新增输入槽、键位和 HUD 布局。
- **AI 多人战术**：已有三档难度、导航、追击 / 射击；集火、掩护、包抄未做。
- **战役平衡**：六关配置 / 解锁 / 成绩完成；六关真人难度曲线和投放节奏未调优。
- **训练跳过**：可自由做其他任务或重置，但没有单独的“跳过本任务”按钮。
- **角色后续项**：C04 衣摆 / 披风 / 围巾惯性；C05 编辑器动作预览；C06 专属表情 / 胜利动作；C07 多地图多角色资源人工验收。

## 3. 内容 / 素材

- **逐枪手绘换弹关键帧、枪口火光帧**：当前是程序化轮廓 + 几何 / 色带、支撑手、家族换弹姿势和程序化火光。
- **真实音色素材**：17 型号已有逐枪合成音高与换弹机械音，仍非真实录音。
- **正式命名 / 品牌确认**：P92、M416、AKM、AWM 等参考名是否在发布前替换为原创名，未处理。

## 4. 人工 / 设备验收

- 4 名真人同帧出界 / 观战体验。
- 参考机、低端 GPU、集成显卡、移动设备性能。
- 实体键盘改键、手柄、鼠标侧键、多显示器。
- 输入延迟矩阵（当前仅本机单次 10.5 ms）。
- 真实用户 profile 的跨浏览器存档迁移。
- 移动端真机触摸操作。
- 长时间运行 GPU 显存 / 崩溃数据（当前 20 局只有 JS 堆数据）。

## 5. 不在当前目标内

- 网络联机、房间匹配、断线重连。
- 账号、排行榜、云存档。
- 观战回放、录像。
- 商业化发布所需的隐私、崩溃上报、完整本地化。

## 建议优先顺序

1. T06.3 独立录键组件 + 手柄。
2. 4 真人输入槽（若确实需要）。
3. AI 集火 / 掩护。
4. 六关人工平衡。
5. 逐枪手绘与真实音色素材。
