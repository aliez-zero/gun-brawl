# 混枪大乱战 · Gun Brawl

TypeScript + Phaser + Vite 的桌面浏览器平台乱斗游戏。当前完成架构基础与第一阶段可玩原型，后续按 [PRD](./docs/PRD.md) 逐步增加内容。

先读 [协作入口](./AGENTS.md)、[开发现状与交接](./docs/DEVELOPMENT.md) 和 [并行任务计划](./docs/PARALLEL_PLAN.md)。通过 [模块任务包](./docs/modules/README.md) 选择独立模块，里面包含子任务清单、依赖、文件范围、验收条件和可直接复制给其他 AI 的开发指令。负责人和状态统一维护在总看板；地图与外观本轮交付见 [接手记录](./docs/updates/2026-10-17-appearance-maps.md)。

所有开发文档、PRD、调研和来源留档均已收进项目。完整目录见 [文档导航](./docs/README.md)。

## 启动

需要 Node.js 22.12+（建议 24 LTS）和 pnpm。

```powershell
cd D:\Code\gun-brawl
pnpm install
pnpm dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173/`。

```powershell
pnpm typecheck   # 严格 TypeScript 检查
pnpm test        # 无浏览器的核心规则与存档测试
pnpm build       # 类型检查和生产构建，输出 dist/
pnpm preview     # 本地预览生产构建
```

浏览器验收另开终端，在开发服务器启动后执行：

```powershell
pnpm test:browser
pnpm test:visual   # 换装、地图选择、保存与响应式验收
```

脚本优先使用 Windows 已安装的 Chrome / Edge；其他环境可先执行 `pnpm exec playwright install chromium`。通过 `GAME_TEST_URL` 可以指定测试站点，通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 可以指定浏览器。截图保存在被 Git 忽略的 `artifacts/`。

## 当前可玩内容

- 主菜单、人机对战、本地双人和自由练习。
- 四张可选地图：云上古城、霓虹天际、星际方舟、训练台，各有独立平台布局和背景。
- 五种角色风格：荒野牛仔、东方浪客、都市特工、星际游侠、古城守卫。五套服装、五种头饰与不戴头饰、八种衣服配色和三种肤色可混搭；P1 / P2 独立保存。
- 重绘的 2D 卡通角色、跑动 / 跳跃 / 开火 / 受击姿态，预览和实战共用同一份角色绘制。
- 正常对局为无限弹药基础手枪；五把非火箭枪的核心、弹量与霰弹弹道已接入测试 / 切枪入口，尚未接入游戏内投放。
- 左右移动、二段跳、起跳宽限、跳跃缓存、单向平台向下穿台。
- 连续射击、独立后坐力与击退、连续弹道碰撞检测。
- 三条生命、出界复活、复活保护、同帧淘汰、计时、加时、结算与重赛。
- 简单启发式 AI，使用与玩家相同的角色指令。
- 失焦与标签页隐藏时暂停、恢复倒计时、音效、减少画面震动。
- 本地设置、最近模式、地图、两位玩家外观和基本战绩保存，兼容原有 v1 存档。

玩家 1：`A/D` 移动，`W` 或空格跳跃 / 二段跳，`S` 穿台，按住 `J` 连射。玩家 2：方向键移动 / 跳跃 / 穿台，按住 `Enter` 或小键盘 `0` 连射（小键盘 Enter 也可）。`Esc` 暂停。

基础手枪每 0.28 秒一发，单发击退 480 逻辑像素/秒，玩家与 AI 使用相同数值。连续命中可以压过向内跑动的抵抗；单发仍保留回台空间。击退会随时间衰减，生命仍仅在出界时扣除。

主菜单点击“角色外观”或“更换地图”即可编辑，修改自动保存。对局中编辑会先暂停，外观和地图在下一局 / 重新开始时应用，当前局保持原配置。

当前没有炸弹、武器箱、战役、改键、复杂导航 AI 或网络联机；特殊枪核心已有，但正常对局无法拾取，火箭仍待 T02。这些内容仍属于后续迭代，不能把本原型视为 PRD 全量完成。

## 架构入口

完整说明见 [架构文档](./docs/ARCHITECTURE.md)。

```text
src/
  app/             应用装配、菜单 / 对局 / 对话框流程
  scenes/          Phaser 启动与对局场景
  game/
    core/          纯 TypeScript 状态、固定步长、对局运行器
    systems/       移动、战斗、生命和胜负规则
    ai/            生成 ActorInput 的 AI
  presentation/    键盘、音效、Phaser 画面适配
  content/         地图、武器和对局配置
  storage/         有版本的本地存档与数据校验
  ui/              DOM 菜单、HUD、暂停、设置与结算
tests/             核心规则与存档的自动化测试
scripts/           浏览器流程检查
docs/              架构、开发现状和并行任务计划
```

`src/game` 不导入 Phaser、DOM 或 localStorage；Phaser 负责呈现，核心碰撞由纯 TypeScript 系统负责。逻辑固定 60 Hz，显示做位置插值。渲染、DOM HUD 和音效通过状态及事件消费战斗结果。
