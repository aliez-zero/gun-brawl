# 混枪大乱战 · Gun Brawl

TypeScript + Phaser + Vite 的桌面浏览器平台乱斗游戏。当前完成架构基础与第一阶段可玩原型，后续按 [PRD](./docs/PRD.md) 逐步增加内容。

## 启动

需要 Node.js 22.12+（建议 24 LTS）和 pnpm。

```powershell
cd D:\Code\gun-brawl
pnpm install
pnpm dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173/`。

**DeepSeek 对战**：复制 `.env.example` 为 `.env.local`，填入 `DEEPSEEK_API_KEY`，重启 `pnpm dev` 后点击主菜单的“DeepSeek 对战”。模型通过状态接口直接操作角色，密钥只在 Node 端使用。配置、预算、延迟和验证边界见 [DeepSeek 接入说明](./docs/DEEPSEEK.md)。没有密钥仍可玩原有模式。

```powershell
pnpm typecheck   # 严格 TypeScript 检查
pnpm test        # 无浏览器的核心规则与存档测试
pnpm build       # 类型检查和生产构建，输出 dist/
pnpm preview     # 本地预览生产构建
```

浏览器验收另开终端，在开发服务器启动后执行：

```powershell
pnpm test:browser
pnpm test:visual   # 换装、地图选择、保存与响应式验收
pnpm test:deepseek # 外部 AI 完整流程；模拟响应，不产生模型费用
```

脚本优先使用 Windows 已安装的 Chrome / Edge；其他环境可先执行 `pnpm exec playwright install chromium`。通过 `GAME_TEST_URL` 可以指定测试站点，通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 可以指定浏览器。截图保存在被 Git 忽略的 `artifacts/`。

## 当前可玩内容

- 主菜单、人机对战、本地双人、自由练习和自定义对局；自定义支持 2—4 人、最多两名本地玩家、逐 AI 难度、地图、生命、时限与武器池。
- 四张可选地图：云上古城（双塔 / 断墙 / 低庭院）、霓虹天际（非对称楼顶 / 广告牌 / 维修通道）、星际方舟（反应堆 / 分离船坞 / 下层气闸）、训练台（开阔主平台）。主题图主要落脚区加宽，下层接应内侧失足，外围保留击出机会。
- 五种角色风格：荒野牛仔、东方浪客、都市特工、星际游侠、古城守卫。五套服装、五种头饰与不戴头饰、八种衣服配色和三种肤色可混搭；P1 / P2 独立保存。
- 重绘的 2D 卡通角色、跑动 / 跳跃 / 开火 / 受击姿态，预览和实战共用同一份角色绘制。
- 六关战役：独立地图 / AI 难度 / 生命 / 时限 / 武器池，胜利解锁下一关并记录最佳成绩；失败或平局不解锁，战役独立于普通人机统计。
- 正常对局仍从无限弹药基础手枪开始；六类标准枪共 17 个具体型号（P92 / P1911 / Deagle、UMP45 / Vector / UZI、M416 / AKM / SCAR-L、S686 / S1897 / S12K、Kar98k / M24 / AWM、RPG-7 / AT4），加特林 / 重炮狙击枪两类终极武器通过武器箱获得；训练场可按 1—8 满弹试类别代表，也可从图鉴直接试任意型号，逐枪使用独立弹匣 / 备弹 / 换弹 / 后坐，并支持换弹。训练场另有六项任务、移动 / 静止假人、局部重置和 17 型号图鉴；图鉴显示逐枪定位、单发威力与持续压制，模型按型号尺寸 / 轮廓区分。
- 左右移动、二段跳、起跳宽限、跳跃缓存、单向平台向下穿台。
- 连续射击、独立后坐力与击退、连续弹道碰撞检测。
- 三条生命、出界复活、复活保护、同帧淘汰、计时、加时、结算与重赛。
- 三档 AI：四图平台导航图、缺口跳 / 穿台 / 下层回台、1 秒无进展重规划；简单 / 普通 / 困难在反应、追击距离、射程和投弹上有可观察差异，使用与玩家相同的角色指令。
- 失焦与标签页隐藏时暂停、恢复倒计时、音效、减少画面震动。
- 本地设置、最近模式、地图、两位玩家外观 / 键位、自定义对局、训练完成 / 首次引导和基本战绩保存；v1 旧档迁移到 v2，最近 20 个结果去重，设置页可确认清档。

玩家 1：`A/D` 移动，`W` 或空格跳跃 / 二段跳，`S` 穿台，按住 `J` 连射，`R` 换弹，`K` 投弹。玩家 2：方向键移动 / 跳跃 / 穿台，按住 `Enter` 或小键盘 `0` 连射（小键盘 Enter 也可），小键盘 `2` 换弹，小键盘 `1` 投弹。`Esc` 暂停。以上均可在“设置 → 键位”中改键、恢复默认；冲突键会提示且不会保存。

基础手枪每 0.28 秒一发，单发击退 480 逻辑像素/秒，玩家与 AI 使用相同数值。连续命中可以压过向内跑动的抵抗；单发仍保留回台空间。击退会随时间衰减，生命仍仅在出界时扣除。

主菜单点击“角色外观”或“更换地图”即可编辑，修改自动保存。对局中编辑会先暂停，外观和地图在下一局 / 重新开始时应用，当前局保持原配置。

当前已有炸弹 / 爆炸、武器箱投放、四图、三档 AI 导航、弹匣 / 备弹 / 换弹、改键 / 键位持久化、自定义 2—4 人对局、训练任务 / 图鉴、六关战役、17 个具体武器型号和两类终极武器；仍没有网络联机。逐枪参数、投放权重和已实现的程序化外观见 [武器型号设计](./docs/WEAPONS.md) 与 [武器外观](./docs/WEAPON_ART.md)；逐枪手绘换弹 / 音色素材和人工平衡仍属后续迭代，不能把本原型视为 PRD 全量完成。

## 架构入口

完整说明见 [架构文档](./docs/ARCHITECTURE.md)。

```text
src/
  app/             应用装配、菜单 / 对局 / 对话框流程
  scenes/          Phaser 启动与对局场景
  game/
    core/          纯 TypeScript 状态、固定步长、对局运行器
    systems/       移动、战斗、生命和胜负规则
    ai/            生成 ActorInput 的 AI
  presentation/    键盘、音效、Phaser 画面适配
  content/         地图、武器和对局配置
  storage/         有版本的本地存档与数据校验
  ui/              DOM 菜单、HUD、暂停、设置与结算
tests/             核心规则与存档的自动化测试
scripts/           浏览器流程检查
docs/              架构、开发现状和并行任务计划
```

`src/game` 不导入 Phaser、DOM 或 localStorage；Phaser 负责呈现，核心碰撞由纯 TypeScript 系统负责。逻辑固定 60 Hz，显示做位置插值。渲染、DOM HUD 和音效通过状态及事件消费战斗结果。
